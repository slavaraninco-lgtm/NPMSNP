# Python MSNP Server (MSN Messenger Protocol)

Полнофункциональный, высокопроизводительный и стабильный сервер протокола **MSNP (Microsoft Notification Protocol)** на Python 3 с базой данных **SQLite** (`database.db`).

Сервер эмулирует официальные серверы MSN Messenger (Notification Server и Switchboard Server), а также предоставляет HTTP-сервер для аутентификации Passport/Tweener и строгую веб-панель управления и регистрации в стиле сайтов нулевых (2000-х).

---

## Возможности

* **Notification Server (NS)** (Порт `1863`):
  * Согласование версий протокола (`VER`): поддержка `MSNP2` – `MSNP12` (MSN Messenger 1.0 – 7.5).
  * Отчет о версии клиента (`CVR`).
  * Двухэтапная аутентификация (`USR`):
    * **MD5 Challenge-Response** (для прямого безопасного входа без сертификатов).
    * **TWN (Tweener / Passport)** (для официальных клиентов MSN Messenger 5.0–7.5).
  * Синхронизация контакт-листа (`SYN`): категории, списки (`FL`, `AL`, `BL`, `RL`, `PL`), телефонные номера (`PRP`, `BPR`).
  * Управление контактами: добавление (`ADD`), удаление (`REM`), переименование (`REA`).
  * Управление группами: создание (`ADG`), удаление (`RMG`), переименование (`REG`).
  * Статусы присутствия (`CHG`): В сети (`NLN`), Занят (`BSY`), Отошел (`AWY`), Невидимка (`HDN`), Не в сети (`FLN`) и др.
  * Мгновенные уведомления о статусе контактов в реальном времени (`ILN`, `NLN`, `FLN`).
  * Персональные сообщения статуса (`UUX` / `UBX` / PSM).
  * Поддержка офлайн-сообщений (OIM): доставка сообщений при входе адресата.
  * Keep-alive пинги (`PNG` / `QNG`).

* **Switchboard Server (SB)** (Порт `1864`):
  * Запрос перенаправления в чат (`XFR SB`).
  * Авторизация вызывающего (`USR`) по одноразовому токену `CKI`.
  * Вызов собеседника (`CAL`): отправка `RNG` адресату через NS.
  * Ответ вызываемого (`ANS`): вход в комнату.
  * Синхронизация состава участников (`IRO`, `JOI`).
  * Передача текстовых сообщений (`MSG`) в формате MIME.
  * Поддержка подтверждения доставки (`ACK` / `NAK`).
  * Индикаторы набора текста в реальном времени (`NOT`).
  * Поддержка Nudge (встряска окна).
  * Корректный выход участников (`BYE`, `OUT`).

* **HTTP Nexus & Web Dashboard** (Порт `1865`):
  * Эмуляция сервиса Passport Nexus (`/rdr/pprdr.asp`).
  * Эмуляция Tweener Login (`/login.srf`).
  * Классический ретро веб-интерфейс в стиле нулевых (`http://localhost:1865/`):
    * Статистика сервера: аптайм, количество онлайн-пользователей, общее число аккаунтов.
    * Список активных подключений.
    * Форма быстрой регистрации новых аккаунтов.
    * Список всех зарегистрированных пользователей.
  * REST API:
    * `POST /api/register` — регистрация аккаунта.
    * `GET /api/status` — JSON-статус сервера.

* **База данных (`database.db`)**:
  * SQLite база данных с автосозданием таблиц `users`, `contacts`, `groups`, `offline_messages`.
  * Режим WAL (Write-Ahead Logging) для максимальной производительности и надежности.

## Быстрый запуск

### 1. Требования
* Python 3.8+ (протестировано на Python 3.11).
* Дополнительные сторонние библиотеки не требуются (используется стандартная библиотека Python: `asyncio`, `sqlite3`, `hashlib`).

### 2. Запуск сервера
```bash
python server.py
```
С флагом подробного логирования:
```bash
python server.py --debug
```
С указанием внешнего IP (если клиенты подключаются по локальной сети):
```bash
python server.py --external-host 192.168.1.50
```

### 3. Веб-панель управления и регистрация
Откройте в браузере:
```
http://localhost:1865/
```
Здесь можно сразу зарегистрировать новые аккаунты (например `alice@msn.local` и `bob@msn.local`) и следить за подключениями.

### 4. Запуск автоматических тестов
Сервер снабжен полным набором автоматических тестов (11 тестов), проверяющих БД, парсинг потока, аутентификацию, присутствие, звонки, передачу сообщений и веб-API:
```bash
python test_msnp.py
```

## Настройка клиентов MSN

### 1. Pidgin / Miranda / Trillian / Retro-клиенты
* **Протокол:** MSN / MSNP
* **Имя пользователя:** `ваш_email@msn.local`
* **Пароль:** ваш пароль
* **Сервер:** `127.0.0.1` (или IP сервера в вашей локальной сети)
* **Порт:** `1863`

### 2. MSN Messenger (патченные клиенты Escargot)
В файле конфигурации клиента (например, `msnmsgr.exe-escargot.ini`):
```ini
[options]
server = 127.0.0.1
```
