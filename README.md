# NPMSNP Server (Go Engine)

Высокопроизводительный сервер протокола Microsoft Notification Protocol (MSNP / MSN Messenger), полностью переписанный на язык **Go**.

## Возможности

- **Полная поддержка клиентов**: Windows Messenger (4.x, 5.x), MSN Messenger (6.x, 7.x, 8.x), Trillian, Miranda IM/NG, IM2, Pidgin, Kopete, msn-pecan.
- **Поддержка диалектов**: MSNP2, MSNP3, MSNP4, MSNP5, MSNP6, MSNP7, MSNP8, MSNP9, MSNP10, MSNP11, MSNP12.
- **Pure Go SQLite (без CGO)**: скомпилирован на `modernc.org/sqlite` без зависимости от gcc/MinGW, работает «из коробки» на Windows и Linux.
- **100% совместимость с базой данных**: полная обратная совместимость со схемой `database.db` и токенами шифрования паролей Fernet/AES (`enc:v1:<token>`). Все существующие пользователи и пароли сохраняются.
- **Служба Switchboard**: полноценные групповые и приватные чаты (порт 1864), системные уведомления от «Служба сообщений MSN» (`system@msn.local`), оффлайн-сообщения.
- **Встроенный Passport / Nexus Mock**: эмуляция серверов аутентификации Microsoft Passport для прямого входа клиентов без внешних сервисов.
- **Веб-панель управления и REST API**: мониторинг онлайн-пользователей в реальном времени, управление аккаунтами, бан, мут, смена паролей, системные оповещения.
- **Утилита управления паролями**: отдельный бинарник `reset-password.exe` для просмотра и сброса паролей в консоли.

## Сетевые порты

| Сервис | Порт по умолчанию | Описание |
|---|---|---|
| **Notification Server (NS)** | `1863 TCP` | Основной порт протокола, список контактов, статусы присутствия |
| **Switchboard Server (SB)** | `1864 TCP` | Сервер чатов и обмена сообщениями (P2P/Relay) |
| **Web & Passport (HTTP)** | `1865 TCP` | Веб-интерфейс администратора и авторизация Passport/Nexus |

> ⚠️ **Важно при запуске на Linux / VPS**:
> Оба порта **1863** и **1864** должны быть открыты в файрволе:
> ```bash
> sudo ufw allow 1863/tcp && sudo ufw allow 1864/tcp && sudo ufw allow 1865/tcp
> ```
> Если клиенты подключаются извне или по локальной сети, укажите внешний IP:
> ```bash
> ./npmsnp --external-host <ВАШ_IP>
> ```

## Запуск и использование

### 1. Запуск сервера

```powershell
# Запуск со стандартными параметрами
.\npmsnp.exe

# Запуск с явным указанием внешнего IP и подробным логом
.\npmsnp.exe --external-host 192.168.1.50 --debug
```

Доступные флаги:
- `--host`: IP адрес для биндинга сокетов (по умолчанию `0.0.0.0`)
- `--external-host`: Внешний или локальный IP для оповещения клиентов (определяется автоматически)
- `--ns-port`: Порт Notification Server (по умолчанию `1863`)
- `--sb-port`: Порт Switchboard Server (по умолчанию `1864`)
- `--http-port`: Порт веб-интерфейса и Passport (по умолчанию `1865`)
- `--db`: Путь к файлу `database.db` (по умолчанию `./database.db`)
- `--debug`: Включить детальное логирование сетевых пакетов

### 2. Веб-панель управления

Откройте в браузере:
```
http://<IP_СЕРВЕРА>:1865/
```
Пароль администратора по умолчанию: `123456` (настраивается через переменную окружения `MSNP_ADMIN_PASSWORD`).

### 3. Управление паролями через консоль (`reset-password.exe`)

```powershell
# Показать список всех зарегистрированных пользователей и расшифрованные пароли
.\reset-password.exe --list

# Установить новый пароль пользователю (или создать нового пользователя)
.\reset-password.exe --user test@msn.local --pass NewPassword123
```

## Сборка из исходников

Для сборки требуется Go 1.20+:

```bash
# Сборка сервера
go build -o npmsnp.exe ./cmd/npmsnp

# Сборка утилиты паролей
go build -o reset-password.exe ./cmd/reset-password

# Запуск всех модульных тестов
go test -v ./...
```
